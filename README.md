# EDUSRC 助手

> 一个面向 EDUSRC 平台的轻量级辅助工具，致力于提供更高效、更便捷的礼品检索与信息查询体验。

## 项目简介

EDUSRC 助手是一款围绕 EDUSRC 平台使用场景打造的辅助工具。项目以简洁、实用、稳定为核心设计理念，持续优化功能体验与交互细节，帮助用户更快速地完成日常操作。
