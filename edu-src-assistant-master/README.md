# EDUSRC助手

## 更新记录

1、支持礼品搜索
2、支持"过滤已兑换"开关按钮：
   - 隐藏库存为0（已兑换完）的礼品
   - 检查每个礼品详情页的"兑换限制 已兑/上限"（已兑次数由平台按个人订单统计、撤销单已扣除），上限减去已兑小于等于0的一并隐藏；实测库存为0的情况极少，兑换上限才是主要判定
   - 检测结果缓存30分钟，开关状态自动记忆，下次打开页面自动生效；搜索结果同样受过滤控制，并显示统计提示
3、支持"仅看可兑换"开关按钮：
   - 金币条件：读取个人主页金币余额（/profile/detail/），隐藏价格超过金币余额的礼品
   - 漏洞要求：解析证书详情页描述中的兑换要求（需提交X个某学校中危/高危/严重或以上漏洞、时间下限等），与"我提交的漏洞"列表（/profile/post/，按学校名+危害等级+日期+状态匹配）比对，不满足的隐藏
   - 已收录状态口径：等待修复/已修复/已发布计入资格，待审核/未通过不计
   - Rank分数类要求（如"Rank3或以上"、"6rank"、"不低于2分"）漏洞列表无分数数据，无法评估 -> 严格模式下直接隐藏（宁缺勿错），由平台下单时校验
   - 学校匹配同时使用详情页"来源"字段和礼品名提取的学校名（兼容学校更名）
   - 结果缓存30分钟，开关状态自动记忆
